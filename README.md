# INSONT

Платформа продвижения в Яндексе, Google и ответах нейросетей.

- Маркетинг-сайт с мегаменю, SEO-страницами, title/description, JSON-LD, sitemap, robots, llms.txt
- Три тарифа под рынок РФ: Старт 4 490 ₽ (увидеть), Базовый 10 790 ₽ (писать), Рост 22 490 ₽ (чинить) — в месяц при годе
- Кабинет с настоящей авторизацией: пароли хранятся только scrypt-хэшами, сессии — httpOnly-куки
- Article Writer: ключ → план → черновик (YandexGPT) → редактор → мета → публикация в WordPress (черновиком)
- SEO-чекер страницы: живой аудит по URL — мета, H1/H2, canonical, индексация, schema, alt, TTFB, ключ в тексте
- Пакетная генерация: CSV со списком ключей → статьи в библиотеку, выгрузка одним файлом
- Ключи: Wordstat API + подсказки Яндекса, посадочные конкурентов по сфере
- Лимиты тарифа считает сервер (промпты/статьи), статьи и WP-реквизиты хранятся на сервере (data/accounts)

Переменные окружения — см. `.env.example` (Wordstat, YandexGPT). Без ключей YandexGPT
генерация работает в demo-режиме (каркасные тексты по шаблонам).

```bash
cd sonara
npm run dev
```

Откройте http://localhost:3000
