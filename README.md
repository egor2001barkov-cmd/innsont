# INNSONT

Платформа продвижения в Яндексе, Google и ответах нейросетей.

- Маркетинг-сайт с мегаменю, SEO-страницами, title/description, JSON-LD, sitemap, robots, llms.txt
- Три тарифа под рынок РФ: Старт 3 990 ₽ (увидеть), Базовый 8 990 ₽ (писать), Рост 19 990 ₽ (чинить) — в месяц при годе
- Кабинет: проекты, обзор видимости, боты, аудит, стратегия, статьи, чат, оптимизация, переупаковка
- Ключи: Wordstat API + подсказки Яндекса, посадочные конкурентов по сфере
- Лимиты: Старт 50 промптов / 1 проект / без задач; Базовый 100 / 1 / нет; Рост 200 / 2 / да

```bash
cd sonara
npm run dev
```

Откройте http://localhost:3000
